# ASCII Art Generator

インタラクティブなターミナルおもちゃ。テキストをアスキーアートに変換したり、マトリックス雨やレインボーバナーを表示します。

## 使い方 / Usage

### Python 版

```bash
python ascii_art.py
```

> 初回起動時に `pyfiglet` を自動インストールします。

### PowerShell 版

```powershell
.\ascii_art.ps1
```

> Windows Terminal (PowerShell 5.1 以上) が必要です。

## 機能 / Features

| # | 機能 | 説明 |
|---|------|------|
| 1 | Text → ASCII Art | テキストをアスキーアートに変換 |
| 2 | Matrix Rain | マトリックス風の雨アニメーション |
| 3 | Rainbow Banner | レインボーカラーのアニメーションバナー |

## 動作環境 / Requirements

| 環境 | 必要条件 |
|------|----------|
| Python | 3.7 以上、`pyfiglet`（自動インストール）|
| PowerShell | 5.1 以上、Windows Terminal（ANSI カラー対応）|
